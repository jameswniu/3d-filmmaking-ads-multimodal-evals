# tools/pii_allowlist.txt
#
# Deliberate suppressions for tools/pii_scan.sh.
#
# Format, one per line:
#   <path-substring>|<label>
#
# <path-substring> is matched anywhere in the finding's absolute path.
# <label> is the exact label from the finding, the fifth field of the
# path:line:CLASS:SEVERITY:label output line.
#
# Example, if the author byline in the README is intentional and reviewed:
#   README.md|owner-identity-token
#
# There are deliberately NO active entries here. Every suppression is a decision
# that something identifying is being published on purpose, so each one should
# arrive in a diff a human read. Prefer the inline marker where you can: putting
# the text pii-allow on the offending line suppresses only that line, where an
# entry here suppresses that label across the whole matched path.
#
# Lines beginning with # are comments. Blank lines are ignored.

# --- active suppressions, each reviewed 2026-07-28 ---
